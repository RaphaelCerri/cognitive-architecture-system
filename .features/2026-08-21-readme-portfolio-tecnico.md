## O que mudou

O README passou a apresentar as capacidades verificáveis do sistema, o mapa técnico, a maturidade de cada área, a arquitetura do repositório e instruções de execução. A apresentação inclui ontologia formal, governança de agentes, fairness assurance, memória institucional, máquinas de estado e os 248 testes executados.

## Por que

O README anterior funcionava apenas como índice institucional e escondia o volume de engenharia e pesquisa existente. A nova versão torna o repositório avaliável por recrutadores e engenheiros sem confundir especificações, experimentos e capacidades prontas.

## Como usar

Abra `README.md` para uma visão humana e técnica do projeto. Use a legenda de maturidade e os links de evidência para distinguir código executável, experimento e roadmap.

## Notas

O texto evita declarar runtime multiagente, RAG, autenticação, observabilidade ou produção, pois essas capacidades ainda não existem no repositório.
