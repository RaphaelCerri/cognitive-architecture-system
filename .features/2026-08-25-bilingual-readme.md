## O que mudou

O README principal passou para inglês e ganhou versão equivalente em português. A apresentação foi condensada em estado verificável, capacidades executáveis, conceitos centrais, execução e limites explícitos.

## Por que

O GitHub não adapta README ao idioma do navegador. Inglês como entrada principal atende recrutadores internacionais e a tradução mantém acesso completo em português.

## Como usar

Use o seletor no topo dos dois arquivos. Documentos de pesquisa e experimentos continuam ligados como evidência aprofundada.

## Notas

O README não promove experimentos a produto ou infraestrutura de produção.
