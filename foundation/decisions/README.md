# Architectural Decision Records

ADRs preservam decisões arquiteturais aceitas, seu contexto, consequências e alternativas. Eles não substituem propostas: uma AP pergunta se uma evolução deve existir; um ADR registra por que uma decisão foi tomada.

Na V1, cada ADR é um objeto de `Knowledge` especializado por `knowledge_type: architectural_decision_record`. Isso não promove ADR a Core Type.

## Estados

- `proposed`: decisão ainda em avaliação.
- `accepted`: decisão vigente.
- `deprecated`: decisão não recomendada, mantida por compatibilidade ou história.
- `superseded`: decisão substituída por outro ADR explicitamente relacionado.
