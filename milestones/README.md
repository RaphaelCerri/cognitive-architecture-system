# Milestones

> **English** · [Português](README.pt-BR.md)

Milestones record incremental units of execution. Each record preserves objective, scope,
validation, decisions, backlog review, limitations, and the next bounded step.

In V1, milestone records are experimental specializations of `Knowledge`, not Core Types. An
implemented milestone remains `pending_review` until it satisfies IHP-001 and receives every
required review or approval.

This directory index is a manually maintained derived view. Milestone frontmatter is the source of
truth.

## V1 review model

- Handoffs authorize bounded implementation work.
- Evidence records what was executed and verified.
- Review dispositions preserve limitations and rejected claims.
- Experimental acceptance does not promote proposals, ontology, schemas, or runtimes to canon.
- Backlog review is required before the next milestone begins.

## V1-M02 and V1-M03

V1-M02 handoffs established the experimental governance, ontology framing, role separation,
fairness assurance, memory, and domain feasibility work. V1-M03 focuses on bounded Knowledge Object
contracts and parser compatibility without rewriting canonical sources.

For the full historical handoff index and individual disposition links, use the
[Portuguese version](README.pt-BR.md) or inspect the milestone files and their frontmatter directly.
