# Milestones

Milestones registram unidades incrementais de execução. Cada registro preserva objetivo, escopo, validação, decisões, backlog review e próximo passo.

Na V1, milestone records são especializações experimentais de `Knowledge`, não Core Types.

Um milestone implementado permanece `pending_review` até satisfazer o IHP-001 e receber as revisões ou aprovações exigidas.

Este índice é uma view derivada mantida manualmente; a fonte de verdade é o frontmatter de cada arquivo. (Índice reconstruído pela auditoria macro, Tier A, 2026-07-23.)
