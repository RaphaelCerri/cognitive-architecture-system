# Roadmap V1

O roadmap define ordem de validação, não uma estrutura permanente. Cada milestone deve terminar funcional, validada, documentada e com revisão do backlog.

1. **V1-M01 — Architectural Decision Filter:** estabelecer o gate para permanência arquitetural.
2. **V1-M02 — Formal Ontology and Constitutional Metamodel:** definir identidade, tipos, relações e extensibilidade antes dos schemas estáveis.
3. **V1-M03 — Knowledge Object Contracts:** estabilizar envelope, schemas e validação dos Core Types confirmados.
4. **V1-M04 — Deterministic Compiler:** compilar objetos para JSON normalizado, índices, manifests e relações derivadas.
5. **V1-M05 — Intelligence and Governance Contracts:** formalizar intenção, decisão, risco, autorização, plano e rastreabilidade.
6. **V1-M06 — Runtime Adapter Contract and Codex Adapter:** provar consumo sem dependência do Core em um runtime.
7. **V1-M07 — Project of Architectural Validation:** reconstruir o Knowledge Inbox e aplicar gates arquiteturais.
8. **V1-M08 — Evolution Feedback:** gerar propostas fundamentadas sem alterar automaticamente a fonte canônica.

Milestones posteriores podem ser refinadas conforme evidências, mas mudanças de sequência com impacto arquitetural exigem atualização documentada e governança adequada.
